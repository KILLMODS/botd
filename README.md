# TG Broadcaster — Telegram Mini App (Apple Glassmorphism)

Полнофункциональное веб-приложение Telegram Mini App для управления ботом рассылок `1.py`, оптимизированное для хостинга на **Vercel** и запуска внутри Telegram WebApp.

---

## ✨ Особенности дизайна и функционала

1. **Дизайн в стиле Apple iOS & Glassmorphism**:
   - Глубокие `backdrop-filter: blur`, полупрозрачные стеклянные карточки с мягким градиентным свечением.
   - Скругленные рамки (`rounded-3xl`, `rounded-full`).
   - Плавные тактильные анимации нажатий, открытий и переходов.
   - Интеграция с Telegram WebApp HapticFeedback (виброотклик при переключениях и действиях).

2. **Нижний Navigation Bar (Floating Dock)**:
   - Полностью скругленный плавающий док с подсветкой активной вкладки и бейджами счетчиков.
   - 4 вкладки:
     - 👤 **Профиль**: ID пользователя, тарифный план, срок действия, прогресс-бар дневных лимитов, подключенные аккаунты, статус подключения к боту.
     - 📱 **Аккаунты**: список зарегистрированных телефонных номеров с кнопкой «Удалить аккаунт». Большая кнопка «Добавить аккаунт» с 3-шаговой авторизацией:
       1. Ввод номера телефона.
       2. Ввод кода подтверждения из Telegram (с возможностью запроса по SMS).
       3. Облачный пароль двухэтапной аутентификации (2FA).
       + Также доступен прямой импорт сессии Telethon (`StringSession`).
     - 📨 **Задачи**: отображение всех рассылок точно как в боте. Карточки задач со статусом, счетчиками отправленных сообщений и ошибок. При клике открывается детальная плашка с возможностью редактирования текста, изменения интервала задержек, включения бесконечного режима (`Loop`) и запуска/остановки.
     - ⭐ **Подписка**: тарифы **Free** (Старт), **Pro** (69 ⭐ / $1.99), **Premium+** (159 ⭐ / $4.49) с поддержкой оплаты через **Telegram Stars** и **CryptoBot (USDT)**.

3. **Синхронизация с ботом `1.py` на bothost.ru**:
   - В скрипт `1.py` встроен легковесный `aiohttp` REST API сервер с CORS.
   - В правом верхнем углу мини-аппа есть кнопка «Настройки», где можно указать URL вашего сервера на `bothost.ru` (например: `https://your-domain.bothost.ru:8080`).
   - Автоматический опрос каждые 7 секунд и мгновенная синхронизация задач, аккаунтов и подписок.
   - Если сервер временно недоступен или перезагружается, мини-апп работает в надежном автономном режиме с сохранением данных.

## 🚀 Деплой на Vercel

1. Подключите ваш GitHub репозиторий к Vercel.
2. Vercel автоматически определит Vite / React:
   - **Framework Preset**: `Vite`
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
3. Нажмите **Deploy**.
4. Полученный URL вставьте в Telegram BotFather в настройках Web App бота:
   - `/setmenubutton` или `/newapp` -> укажите ваш URL с Vercel.

---

## 🤖 Запуск бота `1.py` на bothost.ru

Скрипт готов к запуску:
```bash
pip install telethon aiohttp
python 1.py
```
Бот автоматически запустит Telegram-клиент и REST API сервер для синхронизации с Vercel на порту `8080` (настраивается переменной окружения `WEB_PORT`).
