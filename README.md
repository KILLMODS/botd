# TG Broadcaster — Telegram Mini App (Apple Glassmorphism)

Полнофункциональное веб-приложение Telegram Mini App для управления ботом рассылок `1.py`, оптимизированное для хостинга на **Vercel** и запуска внутри Telegram WebApp.

---

## ✨ Особенности дизайна и функционала

1. **Дизайн в стиле Apple iOS & Glassmorphism**:
   - Глубокие `backdrop-filter: blur`, полупрозрачные стеклянные карточки с мягким градиентным свечением.
   - Скругленные рамки (`rounded-3xl`, `rounded-full`).
   - Плавные тактильные анимации нажатий, открытий и переходов.
   - Интеграция с Telegram WebApp HapticFeedback (виброотклик при переключениях и действиях).

2. **Нижний Navigation Bar (Floating Dock)**:
   - Полностью скругленный плавающий док с подсветкой активной вкладки и бейджами счетчиков.
   - 4 вкладки:
     - 👤 **Профиль**: ID пользователя, тарифный план, срок действия, прогресс-бар дневных лимитов, подключенные аккаунты, статус подключения к боту.
     - 📱 **Аккаунты**: список зарегистрированных телефонных номеров с кнопкой «Удалить аккаунт». Большая кнопка «Добавить аккаунт» с 3-шаговой авторизацией:
       1. Ввод номера телефона.
       2. Ввод кода подтверждения из Telegram (с возможностью запроса по SMS).
       3. Облачный пароль двухэтапной аутентификации (2FA).
       + Также доступен прямой импорт сессии Telethon (`StringSession`).
     - 📨 **Задачи**: отображение всех рассылок точно как в боте. Карточки задач со статусом, счетчиками отправленных сообщений и ошибок. При клике открывается детальная плашка с возможностью редактирования текста, изменения интервала задержек, включения бесконечного режима (`Loop`) и запуска/остановки.
     - ⭐ **Подписка**: тарифы **Free** (Старт), **Pro** (69 ⭐ / $1.99), **Premium+** (159 ⭐ / $4.49) с поддержкой оплаты через **Telegram Stars** и **CryptoBot (USDT)**.

3. **Синхронизация с ботом `1.py` на bothost.ru**:
   - В скрипт `1.py` встроен легковесный `aiohttp` REST API сервер с CORS.
   - В правом верхнем углу мини-аппа есть кнопка «Настройки», где можно указать URL вашего сервера на `bothost.ru` (например: `https://your-domain.bothost.ru:8080`).
   - Автоматический опрос каждые 7 секунд и мгновенная синхронизация задач, аккаунтов и подписок.
   - Если сервер временно недоступен или перезагружается, мини-апп работает в надежном автономном режиме с сохранением данных.

## 🚀 Деплой на Vercel

1. Подключите ваш GitHub репозиторий к Vercel.
2. Vercel автоматически определит Vite / React:
   - **Framework Preset**: `Vite`
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
3. Нажмите **Deploy**.
4. Полученный URL вставьте в Telegram BotFather в настройках Web App бота:
   - `/setmenubutton` или `/newapp` -> укажите ваш URL с Vercel.

---

## 🤖 Запуск бота `1.py` на bothost.ru

Скрипт готов к запуску:
```bash
pip install telethon aiohttp
python 1.py
```
Бот автоматически запустит Telegram-клиент и REST API сервер для синхронизации с Vercel / Mini App на порту `3000` (или настраивается переменной окружения `PORT` / `WEB_PORT`).

## 🌟 Новые возможности обновления

1. **Разноцветные кнопки Telegram Bot API & MTProto (как на скриншоте)**:
   - `primary` (синий цвет): ключевые действия (🚀 «Начать рассылку», ➕ «Создать задачу», сессии Telethon, реферальная система).
   - `success` (зеленый цвет): подтверждения и создание (➕ «Добавить аккаунт», 📲 «По SMS-коду», ▶️ «Запустить», ✅ «Принять условия»).
   - `danger` (красный цвет): закрытие и удаление (⏹ «Остановить», ❌ «Удалить», «Закрыть»).

2. **Очищенный лаконичный текст и форматирование**:
   - Полностью убраны разделительные полоски (`━━━━━━`).
   - Компактные сообщения без простыней текста.
   - Аккуратные эмодзи и читаемая типографика.

3. **Реорганизация кнопок**:
   - «Создать задачу» убрано с главного меню и перенесено прямо в список «Мои задачи».
   - Кнопки «Добавить аккаунт» и «Реферальная система» добавлены в «Личный кабинет» (Профиль).
   - Главное меню стало лаконичным, во главе — яркая синяя кнопка «🚀 Начать рассылку».

4. **Реферальная система**:
   - Персональная ссылка `https://t.me/<bot_username>?start=ref_<user_id>`.
   - Защита от самоприглашений и повторных переходов.
   - Начисление бонусных сообщений при успешном подключении аккаунта рефералом:
     - На тарифе **Free**: **+50 сообщений**
     - На тарифе **Pro**: **+100 сообщений**
     - На тарифе **Premium+**: **+230 сообщений**
   - Бонусные сообщения напрямую суммируются с лимитом рассылок.

5. **Обязательная подписка на канал**:
   - Бот проверяет подписку пользователя на канал перед предоставлением доступа.
   - Настройка канала администратором: `/set_channel @channel_name` (или `/set_channel off` для отключения).

6. **Согласие с условиями и политикой конфиденциальности**:
   - При первом старте отображается обязательное принятие условий с кнопкой «Принять».
   - Ознакомиться с полным текстом можно в любое время через Главное меню -> `ℹ️ Инфо и помощь` -> `📜 Политика конфиденциальности и условия пользования`.
   - Ответственность за безопасность аккаунтов и соблюдение правил против спама возложена на пользователя.

7. **Аналитика и админ-панель (`/admin`, `/stats`)**:
   - Детальная статистика воронки: всего пользователей, нажали «Добавить аккаунт» (конверсия %), нажали «Создать задачу».
   - Количество пользователей с подписками Free, Pro, Premium+ и общее число покупок.
   - Всего созданных задач и количество активных задач в процессе прямо сейчас.
   - Количество успешно подключенных аккаунтов.
   - Статистика рефералов и начисленных бонусов.
